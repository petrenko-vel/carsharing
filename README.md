# CarSharing Application

Современное веб-приложение для сервиса каршеринга, построенное на React и TypeScript.

## Стек технологий

- **Frontend**: React 19 + TypeScript
- **Сборка**: Vite
- **Управление состоянием**: Zustand (с persist в localStorage)
- **Стилизация**: Sass (SCSS) + CSS-переменные
- **Роутинг**: React Router 7
- **Качество кода**: ESLint, Prettier, Stylelint

## Структура проекта

Проект организован по методологии **Feature-Sliced Design (FSD)**:

```text
src/
├── app/                    # Глобальные настройки и точка входа (App.tsx)
├── pages/                  # Страницы приложения
│   ├── home/               # Главная страница
│   ├── booking/            # Страница бронирования (с хранилищем Zustand)
│   ├── order/              # Страница подтверждённого заказа
│   ├── login/              # Страница авторизации
│   └── admin-orders/       # Административная панель — список заказов
├── features/               # Функциональные модули
│   ├── auth/               # Авторизация (AuthLayout, AuthField, валидация)
│   ├── location-step/      # Шаг выбора локации (карта)
│   ├── model-step/         # Шаг выбора модели автомобиля
│   ├── extra-step/         # Шаг выбора дополнительных опций
│   └── summary-step/       # Шаг итогового резюме заказа
├── widgets/                # Самостоятельные блоки интерфейса
│   ├── advantages-slider/  # Слайдер преимуществ с автосменой и анимацией
│   ├── hero/               # Главный экран (Hero + Footer)
│   ├── menu/               # Навигационное меню
│   └── order-summary/      # Сводка по заказу
├── shared/                 # Переиспользуемые элементы
│   ├── hooks/              # Общие хуки (useEscape и др.)
│   └── ui/                 # Базовые компоненты (Button, Input, Modal, Stepper, Header, icons)
├── assets/
│   ├── icons/              # logo.png, orders.svg и другие иконки
│   └── images/             # Изображения автомобилей и слайдера
└── styles/                 # Глобальные стили, переменные, хелперы
```

## Маршруты

| Маршрут | Описание |
|---|---|
| `/` | Главная страница |
| `/login` | Страница авторизации → редирект на `/admin/orders` после входа |
| `/booking/location` | Шаг выбора локации |
| `/booking/model` | Шаг выбора автомобиля |
| `/booking/extra` | Шаг дополнительных опций |
| `/booking/summary` | Итог бронирования |
| `/booking/order/:id` | Страница подтверждённого заказа |
| `/admin/orders` | Административная панель (список заказов) |

## Дизайн-система

Основные CSS-переменные (src/styles/variables.scss):

| Переменная | Значение | Назначение |
|---|---|---|
| `--color-text-primary` | `#3D5170` | Основной цвет текста |
| `--color-blue` | `#3B82F6` | Акцентный синий (кнопки, ссылки) |
| `--color-accent` | `#0EC261` | Акцентный зелёный (бренд) |
| `--color-gray-m` | `#999999` | Вспомогательный текст |

Варианты кнопок (`Button` компонент):

| Класс | Описание |
|---|---|
| `button--hero` | Зелёный градиент, главный экран |
| `button--primary` | Синий, страницы авторизации и админки |
| `button--green` | Тёмно-зелёный градиент |
| `button--blue` | Сине-зелёный градиент |

## Быстрый старт

1. **Установка зависимостей**:

   ```bash
   npm install
   ```

2. **Запуск в режиме разработки**:

   ```bash
   npm run dev
   ```

3. **Сборка проекта**:

   ```bash
   npm run build
   ```

4. **Деплой на GitHub Pages**:

   ```bash
   npm run deploy
   ```

## Проверка кода

- **Линтинг**: `npm run lint`
- **Форматирование**: `npm run format`
- **Проверка стилей**: `npm run stylelint`
